# S3 发射车防空攻击验收记录

## 1. 验收范围

- 分支：`feature/red-defense-marl-upgrade`
- 地图：`/Game/MARL/UrbanDepot/Maps/L_MARL_UrbanDepot`
- 难度：D2
- 固定 seed：`42`
- 攻击单位：`RED_ANTIUAV_01`
- 目标类型：仅 UAV

本阶段只实现 S3 发射车防空攻击。狙击手和步枪兵仍只有 S2 局部感知，不执行 S4/S5 攻击。

## 2. 实现摘要

新增 `UTacticalAirDefenseSubsystem`，状态机为：

```text
Scanning -> Confirming -> Locking -> Warning -> Launching -> Cooldown -> Scanning
                                      \-> LostLock -> Scanning
                                      \-> OutOfAmmo
```

发射车只消费 S2 中 `RED_ANTIUAV_01` 经过距离、FOV 和 LOS 验证的直接联系人，不使用未感知的蓝方坐标。可见联系人内按 `StrikeRole`、Track/`CloseReconRole`、`WideReconRole`、其他 UAV 排序；UGV 不进入候选目标。

命中概率包含距离、相对高度、目标速度、横向规避速度和撞击时 LOS。随机数由 Episode seed 初始化，同 seed、同轨迹产生相同状态序列和命中结果。攻击使用 S1 `UTacticalAgentHealthComponent::ApplyAgentDamage`，默认单次 55 点伤害。弹药容量为 4，单发增加 38 heat，冷却 2.25 秒，heat 超限时延迟再次发射。

UDP 根状态新增 `red_air_defense`。每个蓝方 observation 新增精简 `threat`：`detected`、`locked`、`incoming`、`source_agent_id`、`incoming_direction` 和 `estimated_time_to_impact`。

## 6. 已知限制与 S4 建议

- 当前弹丸是用于训练状态解释的确定性可视弹道，不模拟完整制导飞行物理；撞击时仍重新检查真实 Visibility LOS。
- 五个 S2 传感器与 S3 锁定标记同时开启时调试画面较密，可通过 `tacticalmarl.S2Debug` 和 `tacticalmarl.S3Debug` 分层关闭。
- D2 只攻击 UAV；UGV、狙击手和步枪兵攻击尚未启用。
- S4 应让狙击手继续消费其自身 S2 直接联系人，只攻击 UGV，并复用 S1 伤害接口；不得复用 S3 发射车的目标或读取全局蓝方状态。
