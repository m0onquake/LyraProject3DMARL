# S1 蓝方生命、受击与失能验收记录

- 日期：2026-10-01（Asia/Shanghai）
- 分支：`feature/red-defense-marl-upgrade`
- 地图：`/Game/MARL/UrbanDepot/Maps/L_MARL_UrbanDepot`

## 实现摘要

- UAV 与 UGV 共用可复制、可复位的 `UTacticalAgentHealthComponent`。
- 记录生命值、存活/失能、伤害来源、命中方向和伤害事件计数。
- 蓝方 Observation 增加完整生命状态与普通任务 `action_mask`。
- 失能 UAV 停止接收动作并受控下降；失能 UGV 停驶并显示烟雾、红色灯光和失能文字。
- HUD、世界标签和 roster 读取真实生命值，存活数量随失能同步变化。
- Episode Reset 恢复满生命、初始 Transform、Idle、动作掩码和正常视觉。
- `apply_test_damage` 只在 `-TacticalMARLS1Test` 或 `-TacticalMARLS1AutoDemo` 下可用。

## 已知限制与 S2 入口

- S1 的烟雾为无粒子资源依赖的原生几何动态效果，便于自动构建和 Game 模式验收；后续可在不改变状态接口的前提下替换为 Niagara。
- 测试伤害无红方战术来源，必须显式启动验收参数。真实红方局部感知、共享告警和主动攻击仍未实现，属于 S2/S3。
- S2 建议复用当前统一 Health 接口，但不得让红方读取蓝方全局真值；应先实现带距离、FOV、LOS、置信度和 seed 控制的局部 Threat Sensor。
