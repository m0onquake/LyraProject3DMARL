# S0 基线固化与可视化验收记录

适用分支：`feature/red-defense-marl-upgrade`
目标地图：`/Game/MARL/UrbanDepot/Maps/L_MARL_UrbanDepot`
固定难度：`D0`
固定 seed：`42`

## 实施边界

本阶段只固化现有 3 UAV、3 UGV、3 Rifleman、1 Sniper 和 1 Anti-UAV
Launcher，并增加可视化入口。红方使用 D0 被动模式：保留 Pawn、角色、
武器和 GAS 生命，但暂停原 Lyra Bot 战斗逻辑。未实现蓝方伤害/失能、红方
感知、锁定或攻击；这些属于 S1 及后续阶段。

蓝方在 S0 尚无可受击 Health Component，头顶标签因此明确显示
`Health D0 baseline | ACTIVE`，避免把尚未实现的 S1 生命状态伪装成真实数值。
红方标签显示 GAS 的实际当前/最大生命值。

## 启动与可视验收

```powershell
& 'E:\UE_5.3\Engine\Binaries\Win64\UnrealEditor.exe' `
  'E:\UEproject\LyraProject\LyraProject.uproject' `
  '/Game/MARL/UrbanDepot/Maps/L_MARL_UrbanDepot' `
  -game -windowed -ResX=1600 -ResY=900 -log `
  -TacticalMARLS0AutoDemo -TacticalMARLS0Capture
```

预期可见内容：

- 左上 HUD：`Difficulty D0`、Episode、seed、Episode 状态、step、Mission
  Phase、Track Quality、红方 `UNAWARE`、双方存活数和 `ROSTER VALID 6+5`。
- 蓝方头顶：阵营、JSON Agent ID、UAV/UGV、Role、Task/状态和
  `Health D0 baseline | ACTIVE`。
- 红方头顶：阵营、Agent ID、Rifleman/Sniper/AntiUAV、D0 被动任务、
  `Alert UNAWARE`、真实 GAS HP 和存活状态。
- 世界标记：蓝方基地蓝色圆环、红方防御区红色圆环、发射车金色球/立柱
  及 `PRIMARY OBJECTIVE` 标签。
- 总览相机覆盖蓝方基地和红方防御区。四层可视化可以用
  `tacticalmarl.S0*` 控制台变量独立关闭。

截图固定输出：
`Saved/TacticalMARL/Screenshots/S0_UrbanDepot_seed42.png`。

v1 根字段和逐 Agent 基线字段。报告输出到
`Saved/TacticalMARL/Reports/s0_baseline_check.json`。
